What the log export carries (catalog claude-code 2.1.316; https://code.claude.com/docs/en/monitoring-usage#events)

Flags
  Prompt text: sent as <REDACTED>, because OTEL_LOG_USER_PROMPTS is unset
  Claude's response text: sent as <REDACTED>, because OTEL_LOG_ASSISTANT_RESPONSES is unset, so it follows OTEL_LOG_USER_PROMPTS, which is unset
  Full shell commands, tool input, and MCP, skill and plugin names: sent, because OTEL_LOG_TOOL_DETAILS = 1 (set by environment variable)
  Full model requests and responses, the whole conversation: not sent, because OTEL_LOG_RAW_API_BODIES is unset
  Your managed settings (redacted) and their SHA-256: not sent, because OTEL_LOG_MANAGED_SETTINGS is unset
